3 Rule check

Max individual Max total (incl. relays) Scoring entries per team per event
Checked against UHSAA and NFHS rules: max 2 individual events and 4 events total per swimmer (diving counts as individual). Each event once only. Relays need 4 different swimmers, all the relay's gender, one leg each, from the same school. Exhibition / intersquad: squads of one school may mix on relays and the scoring-entry cap is off; the swimmer limits still apply. A swimmer's 14-meet season limit can't be checked from one meet. 0 = no limit.

7 Seeding

at least 3 swimmers in every heat
Same team lanes and fastest-in-the-middle as Meet Manager's dual seeding, but every heat has at least 3 swimmers — when heat 1 would be short, the slowest swimmers of the next heat move down. Once seeded, the heats update by themselves when entries change, and go into the Meet Manager backup.

Heats after seeding

To move a swimmer, click them, then click the lane to move to — an empty lane moves them, a filled lane swaps the two. Each event has a spare empty heat to move into. Moved lanes are marked moved and go into the Meet Manager backup.

Organize the folder

Reads every backup and entry file in the folder to find which meet it belongs to, then sorts them into season / date + meet name folders, e.g. 2025-26/2025-12-19 THS Mel Roberts Invitational.

Meet board

The pool PC running meet-board (spectator TVs and the stream overlay). MeetDeck sends it the start lists from the meet database, relay swimmers' last names included — on the meet database page, Send start lists.

Phone results

A public, phone-friendly results page for spectators (no login, works on cellular). MeetDeck publishes it to a GitHub Pages site after each scored race; phones see it about a minute later. Put the address on the board.
Token: GitHub → Settings → Developer settings → Fine-grained tokens → only this repository, permission Contents: read and write. It stays on this computer.

MeetDeck for Windows

Runs all of MeetDeck on a Windows laptop, no server needed: unzip, double-click MeetDeck.bat. Comes with your host schools, rules library and meets.

Report font

Meet Manager prints heat sheets, referee programs and timer sheets in Cambria, which comes with Windows. Add your PC's copy and printed reports use it too; without it they use Caladea, a free look-alike with the same letter widths.
Tip: in the file picker, paste C:\Windows\Fonts into the address bar. If the folder only shows "Cambria" tiles, copy those two files to your Desktop first.
